# Audit perbaikan SIDAKSA — 19 November 2026

## Kontrol pemilik

Pemilik menjalankan server operasional sendiri dari PowerShell di `D:\sidaksa` dengan `npm run start`. Asisten tidak memasang autostart dan tidak menyalakan kembali server operasional. Pengujian berikut memakai port/store terisolasi. Sebelum preferensi ini diberikan, baseline browser nyata dan Google/Supabase/API telah diperiksa; baseline tersebut bukan bukti seluruh bug bebas.

## Temuan yang direproduksi

Tercatat 12 temuan: satu kelompok kegagalan startup/recovery, lima frontend dan enam backend. Rincian bukti/status per-ID ada di `.private/evidence/audit-ledger-20261119.json`. Ini daftar terverifikasi dalam cakupan audit, bukan klaim seluruh bug yang mungkin ada.

- Startup: metadata lock bertahan setelah proses mati; PID dapat dipakai ulang layanan Windows. Perbaikan awal hanya mengenali server aktif sehingga tidak mengatasi siklus setelah reboot/abnormal exit.
- Frontend: Reset draft belum diterapkan, company link salah master, pesan ambiguous-ID salah, refresh token menghilangkan input, dan review stale tanpa pemulihan eksplisit.
- Backend: atribut demografis dari relasi identitas tak terverifikasi, audit bergantung snapshot, makna filter partner ganda, urutan partner CSV berbeda, validasi named-month year, dan provenance ekspor kosong.

## Bukti restart terisolasi

- Build lama direproduksi gagal setelah real child Node dipaksa mati, tanpa pembersihan lock manual.
- Implementasi baru memakai guard kernel selama penulis hidup dan metadata identitas kelahiran proses; memulihkan hanya pemilik lama yang terbukti sudah tidak ada/diganti.
- Compiled crash smoke dan perintah Windows **persis `npm run start`** telah lulus start dingin, panggilan ulang exit0 dan restart setelah penghentian paksa pohon proses. Semua pada port selain3080/store privat uji.
- Kasus layanan Windows protected direproduksi lebih lanjut: CreationDate tersedia tetapi ExecutablePath tidak, dan probe signal0 dapat ditolak. Perbaikan lanjutan memisahkan pembuktian birth asing dari verifikasi executable diri sendiri; source repro pada layanan yang sama sekarang berhasil. Tidak ada layanan Windows yang dimatikan/diubah.
- Tes fokus recovery/startup/protected-owner: 76 lulus menurut hasil yang disimpan. Ini subset, bukan jumlah keseluruhan suite.
