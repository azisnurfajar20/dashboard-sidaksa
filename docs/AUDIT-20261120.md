## Perbaikan utama

- **Lock startup:** metadata staging lengkap disinkronkan sebelum publikasi no-replace. Crash sebelum/saat/setelah publikasi, PID reuse, protected process, concurrent restart dan ownership release mempunyai regresi. Preexisting lock ambigu tetap fail-closed, bukan dihapus sembarang.
- **Kompatibilitas cache:** hanya dua representasi legacy yang dapat direproduksi persis yang diterima. Revisi normalisasi masuk ke ID snapshot, sehingga permintaan/review lama tidak berpindah diam-diam. Load bersifat in-memory; cadangan lengkap state asli dibuat sebelum penulisan normal pertama.
- **Auth refresh:** hasil 401 verifikasi lama yang dibatalkan tidak boleh membatalkan generasi baru; 401 request aplikasi dikaitkan dengan token saat request dikirim. Penolakan sesi/token yang masih berlaku tetap fail-closed.
- **Frontend lainnya:** Reset draft, rute entity/kind, pesan ambiguous ID, explicit latest untuk review stale, serta audit tanpa snapshot telah diperbaiki dan diuji.
- **Backend lainnya:** atribut relasi kandidat, filter master mitra, kesamaan urutan CSV/tabel, batas tahun tanggal, serta metadata ekspor kosong telah diperbaiki dan diuji.
