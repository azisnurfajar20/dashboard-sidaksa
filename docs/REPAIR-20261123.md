## Memuat hasil di aplikasi pemilik

Pemeriksaan HTTP baca-saja terhadap HTML/aset CSS pada server aktif telah mencocokkan aset frontend baru dengan hasil build. Untuk tampilan baru, simpan pekerjaan lalu muat ulang browser (**Ctrl+Shift+R** jika halaman lama masih terbuka). Tidak perlu menghapus cache aplikasi, lock, mapping, review, kredensial atau spreadsheet.

Untuk mengaktifkan **backend** yang sudah dibangun:

1. Tekan **Ctrl+C di terminal server yang sedang berjalan**, tunggu shutdown normal.
2. Jalankan sendiri:

```powershell
cd D:\sidaksa
npm run start
```

Start dari terminal kedua saat instansi lama masih hidup akan memakai proses lama, bukan memuat backend baru. Asisten tidak melakukan restart tersebut.

Peringatan kualitas sumber seperti `DUPLICATE_ID`, kolom kosong atau relasi ambigu tetap dilaporkan apa adanya. Memperbaiki software tidak berarti membersihkan atau mengubah data Excel/Sheets tanpa keputusan pemilik.
